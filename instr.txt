  The biggest thing to note is that right now pipeline.py:execute_commands always creates a thumbnail    
  copy at the top (line 33), but only populates it when the thumbnail operation is in the command list — 
  so if no thumbnail operation was requested, thumbnail just stays as the original image copy. You may   
  want to handle that case (e.g., only populate thumbnail_image in the response when the operation was   
  actually requested).
